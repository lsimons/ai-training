## About this template

This is a project template, not a finished site. It gives you a themed
[Astro Starlight](https://starlight.astro.build/) site with a landing page, a
[Quarto](https://quarto.org/) slide-deck setup, and the CI/CD wiring to publish
to GitHub Pages - all under the shared "LSD Warm" theme used across
[lsimons.github.io](https://lsimons.github.io).

Run `mise run init` once to rename `lsimons-template-doc` and `Template Docs`
throughout the repo to your own project, then replace this landing page and the
guides with your content. See the
[getting started guide](/lsimons-template-doc/guides/getting-started/) for the
full walkthrough.
