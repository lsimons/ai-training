## Status

This project was set up on 2026-09-19 and has no lesson content yet. The
[rough plan](https://github.com/lsimons/ai-training/blob/main/docs/plan/README.md)
describes what is coming: interactive lessons in the browser, a topic map, a
project dictionary based on the CS50 approach to teaching, and a tutor mode
that runs the site locally from a Claude Code session.

## Origins

A rebuild of [agent-engineer-course](https://github.com/lsimons/agent-engineer-course),
itself a fork of Addy Osmani's [agent-engineer](https://github.com/addyosmani/agent-engineer)
course. It adopts the pedagogy of Harvard's [CS50](https://cs50.harvard.edu/)
and references the public courses on [Claude Academy](https://academy.claude.com/).
