  temporary HOME, a fixed locale and identity, global and system config

  `GIT_TEMPLATE_DIR` and `GIT_CONFIG_PARAMETERS` through, and runs
  `git diff --stat` with a fixed width.
- An exercise that connects a real MCP server to an agent checks how the
  server takes its allowed folders from the client's roots, and has the
  learner start the agent inside the folder it may touch.

  license page or repository, since two builders defaulted to Proprietary.
- A shell command shown on a page is run on the page's own instructions
  (a fresh copy, macOS sort order) and its output compared with the page.
