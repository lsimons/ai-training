# Session records

The files here are the records of the dispatcher runs and waves up to
2026-09-24, and they stay as history. New records go elsewhere.

Since 2026-09-25 a `/wave` run is recorded in its GitHub issue with the
`dispatcher-run` label, titled `Run: <Name> (<kind>)`, with one comment
per wave report. The session record of each wave is in the body of its
wave pull request. `docs/agents/meta-orchestration.md` ("Runs and run
issues") describes both.
