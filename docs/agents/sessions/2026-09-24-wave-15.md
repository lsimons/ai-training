  reviewers got an empty result, twice with an explicit worktree target,
  and reviewed the fixtures by hand. The reviewer prompt should say to
  start the skill from inside the review worktree and to probe by hand when

  it passes, and reads its input directory with a glob, never `iterdir()`.

  memory files) names the vendor page and matches the current default
  behavior, since three branches described an older behavior.
- A builder never messages the reviewer. One builder told its reviewer that
  a revision was ready, and the lead sent the re-check request as well.
