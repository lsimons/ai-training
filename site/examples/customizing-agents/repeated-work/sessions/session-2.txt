Session 2, September 15: add the due date to the invoice list

This log was written for the lesson "Turning repeated work into something the
agent keeps". No model produced it. The project is a small web shop frontend.
Its instructions file is instructions-before.md, one folder up. A line that
starts with "User:" or "Agent:" is a message. A line that starts with "$ " is
a command the agent ran, and the lines under it are its output.

User: Invoices now have a due date in the billing API. Add a column for it to the invoice list.

Agent: First I'll check whether the generated API client has the due date.

$ grep -n "dueDate" src/api/generated/models/Invoice.ts

Agent: It doesn't. I'll regenerate the client.

$ npm run generate
npm error Missing script: "generate"

$ grep -n "api-client" Makefile
14:api-client:
15:	openapi-generator generate -i $(SPEC_URL) -g typescript-fetch -o src/api/generated

$ make api-client
make: *** [api-client] Error 1: SPEC_URL is not set

User: Set SPEC_URL to https://billing.example.com/staging/openapi.json, it's the staging spec.

$ SPEC_URL=https://billing.example.com/staging/openapi.json make api-client
Generated 41 files in src/api/generated

$ npm test -- src/api
Tests: 18 passed, 18 total

Agent: The client has `dueDate` now. I'll add the column to `src/pages/InvoiceList.tsx` and fetch the invoices with the client.

User: Call the billing API the way this snippet does, through useApi(), so the page gets the loading and error states:

    const { data, error, loading } = useApi(() => invoicesApi.listInvoices());
    if (loading) return <Spinner />;
    if (error) return <ApiError error={error} />;

Agent: Done. The list uses `useApi()` and shows the due date.

$ npm run lint

Agent: The lint error is in a generated file. I'll fix the indentation in `src/api/generated/apis/InvoicesApi.ts`.

User: Don't edit src/api/generated/ by hand. Regenerate the client or change the spec instead.
