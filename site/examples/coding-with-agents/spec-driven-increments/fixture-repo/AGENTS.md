# Agent instructions for todo

- Python 3, standard library only. No new dependencies.
- Tests use `unittest`. Run them with `python3 -m unittest -q`.
- Keep the existing commands (`add`, `list`, `done`, `clear`) unchanged.
- Do not edit `todos.json`; the tests use their own lists.
- When a `SPEC.md` is present, it is the source of truth for the change in
  progress. If the code and the spec disagree, say so and stop.
